# Photo Stories image upload guide

Upload photographs to this folder using the exact filenames below. The Photo Stories page already contains the matching captions and layout. Use JPG or WebP images, preferably landscape (16:10 or 4:3), and keep each image reasonably compressed.

Before uploading, confirm that identifiable people have consented to public use and that organisational, donor, safeguarding and data-protection approvals are in place. Do not upload beneficiary-identifying, sensitive protection, case-management, personal-data, confidential screen or restricted programme images.
