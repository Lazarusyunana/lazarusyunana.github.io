# Lazarus Samson Yunana — Professional Portfolio

A responsive, single-page professional portfolio hosted with GitHub Pages.

**Live site:** https://lazarusyunana.github.io/

## Sections
- Introduction and professional positioning
- About and professional values
- Areas of expertise and tools
- Career experience
- Selected work themes
- Education and professional learning
- Kovara Ltd
- Contact and professional links

## Built with
- Semantic HTML
- CSS (responsive layout, accessible navigation, reduced-motion support)
- Vanilla JavaScript (mobile navigation, scroll progress and reveal-on-scroll)

No build tools, package manager or server-side runtime are required.

## Local preview
Open `index.html` in a browser, or run a local static server from this directory.

## Deployment
The repository is configured for GitHub Pages from the `main` branch. Changes committed to `main` are published by GitHub Pages after its deployment completes.
